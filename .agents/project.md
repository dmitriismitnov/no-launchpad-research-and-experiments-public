# Project architecture

## Layout (minimal)

```txt
src/
  app/            composition and entry wiring
  main.tsx        app bootstrap
  shared/
    styles/
      panda/      hand-written PandaCSS theme
      (../styled-system is generated)
```

## Zones and import rules

- `src/app` - composition and entry wiring.
- `src/shared` - reusable modules, utilities and generated code.
- `src/shared/styled-system` - generated by PandaCSS. Import it, never edit it.
- Imports flow from `app` down to `shared`; `shared` must not import from `app`.

## Aliases

| Alias       | Target         | Must stay in sync                               |
| ----------- | -------------- | ----------------------------------------------- |
| `@app/*`    | `src/app/*`    | tsconfig.json, vite.config.ts, vitest.config.ts |
| `@shared/*` | `src/shared/*` | tsconfig.json, vite.config.ts, vitest.config.ts |

## Styling

- Hand-written theme: `src/shared/styles/panda/`.
- Generated output: `src/shared/styled-system/` (git-ignored). Run `mise run gen` after theme or config changes.
