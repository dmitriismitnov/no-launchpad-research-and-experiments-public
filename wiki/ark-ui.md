# Ark UI

Headless React-компоненты с доступностью и состоянием, стилизуемые снаружи. В migration package упоминается как web-реализация для будущего behavior-слоя, который в v1 сознательно исключён.

Роль здесь — reference: anatomy/parts, состояния и доступность компонентов на момент, когда behavior states выйдут за рамки v1. Построен на [[zag-js]].
