# Backlog

Общая заметка вне эксперимента. Единый индекс отложенной работы.

## Правило

Сюда попадает только осознанно отложенное: то, что не входит в активный
эксперимент и ещё не стало планом. Пункт живёт здесь, пока не превратится в
задачу или отдельный эксперимент — тогда он уходит отсюда в соответствующий
план.

Не сюда:

- то, что уже стало задачей или экспериментом;
- очередь работ следующего цикла — она в [landing-system-roadmap](landing-system-roadmap.md),
  здесь только детали отложенного по источникам.

## typography-asset-foundation

Источники: [README эксперимента](../../experiments/typography-asset-foundation/README.md),
[notes/results](../../experiments/typography-asset-foundation/notes/results.md),
харденинг ветки `experiment/font-pipeline-hardening` (2026-09-30).

### Шрифтовой pipeline

- **Unicode subsetting.** Не делается намеренно: профили (`latin`,
  `latin-cyrillic`, `all`) не проверялись, а subset по текстам проекта
  рискованно вырезал бы будущий контент. Чтобы вернуться, нужно сначала
  измерить реальный лендинг и зафиксировать профили.
- **`preload` критичного начертания.** Не добавлен: сначала нужен замер, какое
  начертание критично. Сейчас оба WOFF2 грузятся одинаково, через
  `font-display: swap`.
- **Публичный API вариативных осей.** `font-variation-settings` и OpenType
  features наружу не выведены; `opsz` остаётся браузерным
  (`font-optical-sizing: auto`). Возвращаться при появлении дизайн-требования.
- **Деструктивное обновление шрифта.** Навыка уровня `update-icon-set` нет:
  смена семейства — ручная операция. Нужен, когда семейство придётся менять
  при живом лендинге.
- **Вторая семья и замена Inter.** Не затрагивались.
- **Вес raw-источников в репозитории.** Оба variable TTF (~1.7 MiB)
  закоммичены как канонический вход. Решить, остаётся ли это приемлемым.
- **Греческое покрытие.** Источник заявляет `latn`, `cyrl`, `grek`; визуально
  подтверждена только кириллица.
- **Статический фолбэк.** Статический набор Inter удалён из репозитория; при
  необходимости вернуться к статике исходники нужно брать из апстрима заново.

### Типографическая foundation

- **Composite text styles и именованные роли.** Сознательно не вводились:
  foundation отдаёт только атомы, а компонент собирает типографику сам
  (подтверждено на `Button.label`). Возвращаться, когда типографика повторится
  в 3+ компонентах и дублирование станет дороже явного слоя.
- **Responsive- и density-шкалы.** Размеры не зависят от breakpoint, диапазон
  `xs…xl` фиксирован. Решить до того, как шкала обрастёт потребителями.

### Тулинг и тесты

Харденинг закрыл однопроходную валидацию, generated CSS и drift-проверку;
отложено:

- **Нереентрантность `wawoff2.compress`.** Ограничение зафиксировано только
  комментарием вызывающего кода (`buildFontAssets`), а не doc-комментарием
  `buildWoff2`. Второй вызывающий легко нарушит. Уже приводило к реальной
  регрессии сборки.
- **Тест путей платит за полную сборку.** `targets the committed generated
  artifact paths` вызывает `buildFontAssets()` (секунды), чтобы сравнить две
  экспортированные константы.
- **«Ровно один импорт» не проверяется.** `Font.test.ts` использует `toContain`,
  поэтому дублирующий импорт generated CSS пройдёт.
- **`satisfies` ради Knip.** Аннотации `satisfies BuiltFontAsset` /
  `satisfies BuiltTextAsset` в тесте существуют только чтобы Knip не считал
  типы мёртвыми.
- **Ветка `missing generated css` не покрыта.** Протестирован только случай
  расхождения, хотя `checkFontAssets` обрабатывает и отсутствие файла.

### Документация

- **Написание артефактов.** `AGENTS.md` говорит «assets, manifest and CSS»,
  соседние `README.md` и `.agents/workflows.md` — «WOFF2 … generated». Свести к
  одному написанию.
- **Обновление visual-baseline.** `notes/results.md` описывает осознанное
  обновление baseline прошлого прогона; харденинг прошёл без обновления, и
  формулировка читается как утверждение о текущем состоянии.
- **Детерминизм в README эксперимента.** Пункты перечисляют WOFF2 и manifest,
  но не generated CSS, который теперь тоже хешируется и проверяется.
