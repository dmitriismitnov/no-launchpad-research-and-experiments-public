# Роли проекта

Общая заметка вне эксперимента. При работе над проектом нужно явно вводить
разные роли, каждая из которых отвечает за свой scope.

## Ветки и роли

Дизайн:

- **Дизайнер** — занимается техническими вопросами, связанными с дизайном.
- **Дизайнер-лид** — координирует задачи дизайна.

Программирование:

- **Программист** — реализует задачи по программированию.
- **Программист-лид** — координирует работу программистов.

Архитектура:

- **Архитектор** — занимается разработкой направления, созданием архитектуры и
  подбором инструментов.
- **Главный архитектор** — координирует работу всех архитекторов и принимает
  решения на уровне всей системы.

Продукт:

- **Продукт-менеджер** — создаёт последовательность задач на основании
  консилиума лидов и далее следит за выполнением задач по последовательности.
- **Владелец продукта** — выставляет цели проекта с бизнесовой точки зрения и
  следит за их выполнением.

Координация:

- **Демиург** — создаёт верхнеуровневые политики координации и следит за тем,
  чтобы ни одна из веток не перетягивала решение на себя.

## Принцип

Явное разделение ролей фиксирует ответственность за scope и не даёт одной
ветке перетягивать решение на себя.
