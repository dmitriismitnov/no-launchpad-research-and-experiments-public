# Card Media Skeleton — history

- 2026-09-30 — эксперимент открыт. Вопрос, scope, принятые решения и критерии —
  `README.md`.
- 2026-09-30 — создан ассет `card-media.skeleton.svg` (до открытия
  эксперимента, по согласованному в чате дизайну): `viewBox="0 0 1600 900"`,
  `preserveAspectRatio="xMidYMid slice"`, поверхность `currentColor` +
  `fill-opacity="0.1"`, глиф «картинка» (рамка, гора, солнце) на `0.3`.
  Отклонены по ходу дизайна: анимированный shimmer и зашитая палитра.
- 2026-09-30 — проверки ассета: `xmllint --noout` — XML корректен; рендер через
  Playwright и визуальный осмотр — light (`#101828`) на белом, dark (белый) на
  `#0a0a0a`, светлый tone (`#98a2b3`), сжатие до 320px. Везде `currentColor`
  наследуется, кадр держит 16:9, глиф читается. `mise run check` не затронут:
  `outputs/**` исключён в `.dprint.jsonc` и `eslint.config.mjs`.
- 2026-09-30 — не проверено и остаётся открытым: поведение в не-16:9
  контейнере; подключение через `?raw` + inline; поведение внутри реального
  `Card`; Storybook и visual-тесты. Проверки сознательно не проводились — по
  явному запросу пользователя «достаточно только ассета».
- 2026-09-30 — **закрытие эксперимента**. Статус: `completed`.
  - Вывод пользователя: эксперимент **случайный**; цель была узкой — просто
    попробовать, может ли DeepSeek сгенерировать SVG. Ответ: **может**.
  - Эксперимент не являлся проверкой контракта изображений; вопрос в
    `README.md` («нужен ли изображениям pipeline») оказался шире фактического
    замысла и остаётся нерешённым.
  - Подтверждение ограничено: один ассет, один визуальный осмотр рендера
    (light/dark/светлый tone, сжатие до 320px) плюс `xmllint`. Сравнения с
    другими моделями, повторных прогонов и сложной графики (фотореализм,
    персонажи, многоцветность) не было.
  - Если тема вернётся — открытые пункты: поведение в не-16:9 контейнере;
    `?raw` + inline и наследование `currentColor`; поведение внутри реального
    `Card`; нужен ли изображениям собственный pipeline.
