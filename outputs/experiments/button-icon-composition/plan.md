# Button Icon Composition — план реализации

Не выполняется до отдельного сигнала пользователя. Чек-лист для будущей
реализации; основание — `README.md`.

## Решения по умолчанию

- Публичный API: `prefixIcon?: IconName`, `suffixIcon?: IconName`.
- Внутренний `_Button` — в `src/shared/components/button/button.tsx`, без
  экспорта.
- Соответствие размеров: `sm → sm`, `md → sm` (оба слота `x8`), определено
  рядом с recipe в модуле `Button`.
- Миграция существующих вызовов с узлами — часть задачи, а не отдельная
  задача.
- Сравнительный вариант B реализуется только если он нужен для доказательства;
  иначе сравнение ведётся по коду и метрикам без постоянной второй версии.

## Задачи

### 1. Baseline
- [ ] Зафиксировать текущие usages `prefixIcon` / `suffixIcon` (src, stories,
      tests, visual).
- [ ] Зафиксировать DOM, размеры слотов и внешний вид кнопок как эталон для
      сравнения «до / после».
- Проверка: список usages и текущий visual baseline.

### 2. Достаточность контракта Icon
- [ ] Проверить, хватает ли `IconName`, `IconSize` и наследования цвета.
- [ ] Решить, нужны ли runtime-список имён или map `key → name`; добавлять

- Проверка: обоснованная запись решения; без изменений публичного API `Icon`,
      если они не нужны.

### 3. Внутренний `_Button` и публичный `Button`
- [ ] `_Button` принимает `ReactNode` в prefix/suffix; владеет DOM, слотами и
      recipe.
- [ ] Публичный `Button` принимает имена, создаёт `Icon`, передаёт готовые узлы
      в `_Button`.
- [ ] Добавить типизированное соответствие `ButtonSize → IconSize`.
- [ ] Не добавлять DOM-обёртку и не дублировать стили.
- Проверка: `mise run check:types`.

### 4. Миграция потребителей и stories
- [ ] Перевести `App.tsx` и `Button.stories.tsx` на имена иконок.
- [ ] Убрать ручное создание `Icon` и ручной выбор размера/цвета у потребителя.
- [ ] Проверить icon-only кнопку (доступное имя через `aria-label`).
- Проверка: `mise run check`.

### 5. Проверки контракта и поведения
- [ ] Типы: `ReactNode` и неизвестное имя отклоняются.
- [ ] Unit: соответствие `ButtonSize → IconSize` покрывает все размеры и

- [ ] `_Button` не экспортируется (Knip / barrel).
- [ ] Browser/Storybook: размеры glyph и слота, наследование цвета в

- Проверка: `mise run test:unit`, `mise run test:browser`, `mise run check:deps`.
