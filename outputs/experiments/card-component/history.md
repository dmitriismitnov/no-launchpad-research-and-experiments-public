# Card Component — history

- 2026-09-30 — эксперимент открыт. Ветка `experiment/card-component` от `main`.
  Зафиксированы вопрос, scope, модель и критерии успеха (`README.md`).
- 2026-09-30 — согласован дизайн Card v1 в чате (brainstorming): статический
  `<article>` без `onClick`, универсальный API, медиа `src`/`alt` с заглушкой,
  `actionButton` как `ButtonProps`, `footer.primaryNote`/`secondaryNote`.
  Детали — `notes/design-spec.md`.
- 2026-09-30 — записан детальный план реализации (`plan.md`).
- 2026-09-30 — реализация по плану в четырёх задачах (коммиты `4e037eb..9a8b448`):
  - preset и регистрация в точке сбора (`cf9011e`);
  - ассет `card-media.skeleton.svg` перенесён рядом с компонентом (побайтово),
    компонент, barrel, composition-тесты (`1c4b428`);
  - stories и browser-проверки (`10be4eb`).
- 2026-09-30 — два исполнения отличались от плана и перенесены в спецификацию:
  - **заглушка встроена inline** (`?raw`), а не `<img alt="">`: граница
    изображения блокирует `currentColor`, поэтому `<img>` дал бы чёрную заглушку
    в dark. Это закрывает открытый вопрос `card-media-skeleton` о `?raw` + inline
    и наследовании `currentColor`;
  - **футер** собран `justifyContent: "flex-end"` плюс автоматический end-margin
    у `footerPrimary`, а не `space-between`.
- 2026-09-30 — визуальная проверка через Playwright и Chromium нашла реальный
  CSS-баг: PEN-значение `justifyContent: "space_between"` невалидно и
  отбрасывается браузером; `Panda` его не переводит. Исправлено на
  `space-between` и закрыто регрессионным тестом (`2187c62`).
- 2026-09-30 — интеграционные проверки: `mise run check` (157 unit, 33 browser),
  `check:deps` — зелёные; barrel зарегистрирован в `knip.jsonc`; регрессионный
  тест сборки пресетов дополнен `card` (`301a0db`, `5661a6a`, `9a8b448`).
- 2026-09-30 — независимое ревью (`openai/gpt-6.1-sol`, чистый контекст):
  0 Critical, 2 Important, 1 Minor. Исправлено:
  - пустые и пробельные опциональные тексты больше не создают пустую область и
    разделитель без содержимого (`7ca1b5f`);
  - выравнивание футера: одинокая вторая заметка прижата вправо, при заметках и
    действии вторая заметка стоит вплотную перед кнопкой (`a8bb646`);
  - спецификация, README и заметка в плане приведены в соответствие с
    реализацией (`5396308`).
- 2026-09-30 — эксперимент **не закрыт**: закрытие — по прямой команде
  пользователя. Ветка `experiment/card-component` не влита.
- 2026-09-30 — по пользовательскому review устранены все рекомендации:
  - media sizing заменён с невалидного `full` на `100%`; локальная квадратная
    PNG fixture в browser-story проверяет успешную загрузку, `object-fit: cover`
    и заполнение 16:9 media-слота;
  - публичный `CardProps` и runtime-очистка исключают пользовательский
    `dangerouslySetInnerHTML`, который конфликтовал с owned children;
  - `actionButton.size: undefined` теперь сохраняет Card-default `sm`;
  - browser-проверки закрепляют фактические light/dark цвета, а
    `FooterAlignments` больше не показывает неработающие controls;
  - комментарии рядом с кодом сокращены до неочевидных причин, а spec/README/
    execution log синхронизированы с фактическим доказательством.
  Итоговый прогон: `mise run check` — 164 unit / 34 browser, `check:deps` —
  зелёный. Эксперимент остаётся открыт.
