# Эксперимент: Card Component

**Статус:** in progress (2026-09-30).

Ветка: `experiment/card-component` от `main`.

## Вопрос

Как собрать составной `Card` так, чтобы он выражал референс `Card / Catalog`
из PEN-макета, но оставался универсальным переиспользуемым компонентом — и что
этот первый составной компонент покажет о границах текущей модели (preset,
слоты, композиция, работа с ассетом)?

## Классификация

Это **дизайн-эксперимент** («как это должно быть устроено»), а не проба
способности: нужны очерченные scope и критерии. Первый составной компонент —
явный пункт roadmap (`landing-system-roadmap.md`, п. 5).

## Scope

В рамках:

- компонент `Card` в `src/shared/components/card/` (компонент, preset, barrel,
  тесты, stories);
- универсальный публичный API, не кодирующий предметные данные каталога;
- 16:9 медиа и заглушка из уже подготовленного ассета
  `card-media.skeleton.svg`;
- действие в футере через существующий `Button`;
- регистрация пресета в явной точке сбора `src/shared/styles/index.ts`;
- проверки, принятые в проекте (unit, composition, Storybook, `check`);
- выводы о модели компонента и границах переиспользуемости.

Вне рамок:

- `onClick`, кликабельная карточка, ссылка, hover/keyboard-поведение;
- `children` и произвольные ReactNode-слоты, compound-API (`Card.Root`, …);
- визуальные и size-варианты, responsive-типографика, состояния загрузки и
  fallback при ошибке изображения;
- собственный pipeline изображений — ассет остаётся самодостаточным файлом;
- миграция потребителей и другие задачи roadmap (`Input`, целевой лендинг).

## Модель (принятые решения)

Согласована в чате до реализации.

- **Один статический `<article>`.** `Card` владеет всей внутренней структурой и
  не принимает `children`. Интерактивность — только у кнопки в футере; у самой
  карточки нет `onClick`.
- **Публичный контракт:**

  ```ts
  type CardProps = Omit<ComponentProps<"article">, "children"> & {
      title: string;
      description?: string;
      media?: { src: string; alt: string; };
      header?: { label?: string; icon?: IconName; };
      footer?: { primaryNote?: string; secondaryNote?: string; };
      actionButton?: ButtonProps;
  };
  ```

- **Анатомия слота recipe:** `root / media / body / header / title /
  description / footer / footerPrimary / footerSecondary / actionButton`.
- **`title` — обязателен** и рендерится как `h3`; вызывающий обязан встроить
  Card в документ с подходящей иерархией заголовков.
- **Медиа — всё или ничего.** Передан `media` → `<img src alt>`; не передан →
  локальный SVG-ассет, **встроенный inline**, а не `<img alt="">`: граница
  изображения блокирует `currentColor`, поэтому inline-форма и даёт заглушке
  наследовать цвет медиа-слота в обеих темах. Обёртка заглушки помечена
  `aria-hidden`; ассет — доверенная локальная константа без `id`. Сетевую
  ошибку Card не обрабатывает (заглушка — только ветка «нет media»).
- **Пустой текст = отсутствие.** Пустая или пробельная строка в
  `description`, `header.label` или заметке футера не создаёт область (иначе
  появляется пустой блок и разделитель без содержимого). `media.alt` —
  исключение: пустой `alt` значим.
- **`actionButton` — это `ButtonProps`**, а не урезанная копия API `Button`.
  Card передаёт `size="sm"` до спреда, поэтому явный `size` потребителя
  побеждает. Это компромисс между «жёстким узким контрактом» и «любым
  `ReactNode`».
- **Нет визуальных вариантов.** Одна проекция по референсу, цвета и
  типографика — из существующих semantic/foundation токенов, без веток
  `_light` / `_dark` внутри recipe.
- **Референс — композиция, а не API.** Данные каталога (`01`, `gauge`,
  `0…400 бар`, `4…20 мА`) живут в Storybook-истории `CatalogReference`, а не в
  публичном контракте Card.
- **Ассет переносится, а не пересобирается.** Копия
  `card-media.skeleton.svg` кладётся в `assets/` компонента; исходник в
  `card-media-skeleton` остаётся как запись эксперимента.

## Критерии успеха

- Card доступен потребителю как самостоятельный компонент и следует принятой
  организации модуля (компонент, preset, barrel, stories, тесты).
- Публичный API универсален и не содержит каталоговых полей.
- Медиа всегда присутствует: переданный источник или декоративная заглушка.
- Пустые опциональные области не рендерятся.
- `actionButton` создаётся самим Card и уважает явный `size`.
- Референс `Card / Catalog` воспроизводится как Storybook-композиция в light и
  dark.
- Обязательные проектные проверки проходят; выводы о модели и границах
  зафиксированы.
- Закрытие — по прямой команде пользователя.

## Состояние (2026-09-30)

- Компонент реализован на ветке `experiment/card-component`:
  `src/shared/components/card/` (компонент, preset, barrel, ассеты, unit,
  composition и browser-проверки, 8 stories).
- Пресет зарегистрирован в явной точке сбора `src/shared/styles/index.ts`;
  регрессионный тест `src/shared/styles/presets.test.ts` дополнен `card`;
  barrel зарегистрирован в `knip.jsonc` как entry-точка.
- Два исполнения отличались от плана и перенесены в спецификацию: заглушка
  встроена inline (`?raw`), а не `<img alt="">`; футер собран
  `justifyContent: "flex-end"` + автоматический end-margin вместо
  `space-between`.
- Визуальная проверка референса через Chromium нашла реальный CSS-баг:
  PEN-значение `justifyContent: "space_between"` невалидно и молча
  отбрасывается браузером. Исправлено и закрыто регрессионным тестом.
- Проверки: `mise run check` и `mise run check:deps` — зелёные.
- Независимое ревью (`openai/gpt-6.1-sol`, чистый контекст): 0 Critical,
  2 Important, 1 Minor. Важное закрыто: пустые/пробельные опциональные тексты
  больше не создают пустой области; выравнивание футера исправлено и покрыто
  геометрическими browser-проверками. Minor (рассогласование спецификации с
  inline-заглушкой) закрыт обновлением документации.
- Открытые ограничения: нет публичных вариантов (`tone`/`size`); заголовок
  жёстко `h3`; у семантического слоя нет отдельной роли «приглушённый текст на
  поверхности», поэтому используются `.background`-проекции. Их контраст
  покрыт тестом Card, но foundation по-прежнему не проверяет эти
  cross-projection пары как системное правило.
- Эксперимент **не закрыт**: закрытие — по прямой команде пользователя. Ветка
  не влита.
