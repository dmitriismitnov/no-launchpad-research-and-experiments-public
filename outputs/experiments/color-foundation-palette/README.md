# Эксперимент: Color Foundation Palette

**Статус:** completed (2026-09-22).

## Вопрос

Как должна быть устроена цветовая палитра foundation-слоя, чтобы она не
разрасталась и была проверяемой, а существующие system-роли переходили на неё
без изменения текущего дизайна.

## Scope

В рамках:

- правила построения палитры (`staticPalette`) и ролей (`roles`);
- минимальный набор семейств под текущий проект: `neutral`, `brand`, `danger`;
- миграция существующих ролей на ссылки к палитре без изменения light/dark
  результата;
- попытка сократить и структурировать список ролей;
- проверка PandaCSS-проекции: static tokens, ссылки и native `colorPalette`;
- Storybook-галерея foundation-цветов.

Вне рамок:

- semantic tokens и смена текущей модели ролей;
- тени и elevation (`shadowColors` остаётся как есть, развилка вынесена в notes);
- breakpoints, motion, density;
- изменение постоянных правил в `wiki/`;
- интеграция с PEN/дизайн-программой: вынесена в отдельный исследовательский
  трек — `../../shared/notes/pen-design-system-integration.md`.

## Успех

- `staticPalette` содержит `neutral`, `brand`, `danger` с полной шкалой `50…950`.
- Текущие значения ролей остаются точками палитры; light/dark результат не
  меняется.
- Роли структурированы и ссылаются на палитру.
- `mise run gen` компилирует палитру и роли; native `colorPalette` проверен.
- Storybook показывает шкалы и роли в light/dark.
- `mise run check`, `mise run check:deps`, `mise run build`,
  `mise run storybook:build`, browser и visual тесты проходят.
- Зафиксированы правила палитры, допустимая семантика ролей и выводы по
  PandaCSS-проекции.

## Итог

Эксперимент закрыт. Проверено, что статическая палитра `staticPalette` и
структурированные `roles` работают в PandaCSS без semantic tokens, дизайн не
меняется, а foundation-имена не привязаны к компонентам.

- Все критерии успеха выполнены; выводы зафиксированы.
- Роли переименованы и сгруппированы, но их число не сократилось: каждое
  значение нужно интерфейсу, слияние изменило бы дизайн (см. `notes/results.md`).
- Вынесено за пределы эксперимента и не блокирует закрытие: нормализация
  `neutral`, elevation/`color-mix()`, проверка на multipart-компоненте,
  интеграция с PEN (отдельный трек), кристаллизация правил в `wiki/`.
